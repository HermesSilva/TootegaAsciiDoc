== Text and inline formatting

Plain text with *bold*, _italic_, `monospace`, #highlighted#, ^superscript^ and ~subscript~. The **un**constrained
forms work inside wo**rd**s, with __ita__lic and ``mono``space. Roles style a span: [.underline]#underlined#,
[.line-through]#struck#, [.big]#big# and [.small]#small#.

Character replacements: (C) (R) (TM) -- ... -> <- => <= and "`curly`" and '`single`' quotes. Entities and
intrinsics: {nbsp}non-breaking space, {zwsp}zero-width space, {deg}, {plus}, {amp}, {lt}, {gt}, {startsb}{endsb},
{caret}, {tilde}, {backslash}, {backtick}, {cpp}.

Attribute reference: the product is {product}, it needs VS Code {min-version} or later. An unset attribute drops
out: [{promo-note}]. Backslash escapes: \{product} stays literal, and so does \*not bold*.

Hard line break +
continues on the next line of the same paragraph.

[%hardbreaks]

is kept
without the plus sign.

Inline passthrough: +++<u>raw HTML</u>+++ and pass:q[*with* substitutions]. Literal `+{product}+` does not
substitute the attribute.
