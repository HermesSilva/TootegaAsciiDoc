== Inline formatting

Text can be *bold*, _italic_, `monospace`, #highlighted#, ^superscript^ and ~subscript~. Links work as bare URLs
(https://asciidoc.org) or with text: https://docs.asciidoctor.org[Asciidoctor documentation]. Keyboard shortcuts
use kbd:[Ctrl+Shift+V], buttons use btn:[Save] and menus use menu:File[Export > PDF].

A footnote goes here.footnote:[Footnotes are collected at the end of the published document.] A cross reference
points to <<tables>> or to <<_images_and_media,the images section>>.
